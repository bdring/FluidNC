FluidNC Demonstration

This is FluidNC running in a browser. It is compiled to Web Assembly code from the real FluidNC source. It cannot access actual machine hardware, but it can process GCode and simulate motion. It has a minimal config.yaml and a sample SD card. Files you change or upload, and settings you change, are saved in this browser and override the built-in copies on the next visit; reload the page to apply a changed config.yaml. Input editing works the same as on a FluidNC running on an ESP32.
